# EcoAlert & Hazard Dashboard

Real-time crowdsourced environmental incident reporting and early warning dashboard built for community hazard visibility.

## Features
- **Flexible Hazard Reporting:** Custom hazard type input with automated datalist suggestions.
- **Incident Categorization:** Priority risk badges (High, Medium, Low) and description fields.
- **Local-to-Cloud Architecture:** Built with AWS SDK v3 for DynamoDB integration, with a seamless in-memory fallback for local testing.

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
- **Backend:** Node.js, Express.js
- **Cloud Database:** AWS SDK v3 (DynamoDB)
